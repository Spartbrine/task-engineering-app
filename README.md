# Task Engineering App

Proyecto de practica para la asignatura **Desarrollo Web Integral** (Cuat. 9D) sobre el flujo de trabajo **GitLab Flow / GitHub Flow**.

## Descripcion

Aplicacion web sencilla de gestion de tareas, usada para practicar el trabajo colaborativo con ramas, Pull Requests y resolucion de conflictos.

## Estructura del proyecto

\`\`\`
task-engineering-app/
|
|- index.html        # Pagina principal
|- about.html        # Pagina "Acerca de"
|- css/
|   |- styles.css    # Estilos del sitio
|- js/
|   |- app.js        # Logica de la aplicacion
|- README.md
\`\`\`

## Flujo de trabajo (GitLab Flow)

1. Cada integrante crea su rama: \`git checkout -b feature/nombre-funcionalidad\`
2. Desarrolla su funcionalidad y hace commits.
3. Sube la rama: \`git push origin feature/nombre-funcionalidad\`
4. Abre un **Pull Request** hacia \`main\`.
5. Revision y **merge**.

## Ramas de funcionalidad

- \`feature/navbar\` - Barra de navegacion.
- \`feature/task-form\` - Formulario para agregar tareas.
- \`feature/about-page\` - Contenido de la pagina Acerca de.
